## 2. Flat-IR Ablation Verification

### Token Distribution (eval_flat.jsonl, 402 examples)

| Token | Count | Percentage |
|-------|-------|------------|
| SLOT | 63,997 | 66.56% |
| E | 15,034 | 15.64% |
| O | 9,783 | 10.17% |
| R | 4,597 | 4.78% |
| A | 1,941 | 2.02% |
| GRAPH_BEGIN | 402 | 0.42% |
| GRAPH_END | 402 | 0.42% |

**Total tokens:** 96,156  
**Unique tokens:** 7

### SLOT Fraction Verification

**Claimed:** 66.56%  
**Verified:** 63,997 / 96,156 = **66.56%** ✅

### Baseline Perplexity Computations

#### Unigram Baseline

```
P(token) = count(token) / total
Cross-entropy = -mean(log2(P(token_i)))
Perplexity = 2^cross-entropy
```

**Result:** Perplexity = 2.8967  
**Interpretation:** A model that always predicts based on token frequency.

#### Bigram Baseline

```
P(token_i | token_{i-1}) = count(token_{i-1}, token_i) / count(token_{i-1})
```

**Result:** Perplexity = 2.3761  
**Interpretation:** A model that predicts based on the previous token.

#### Neural Model

**Result:** Perplexity = 1.0551 (from variant_flat/results.json)

### Comparison Table

| Model | Perplexity | bits/token | vs Neural |
|-------|------------|------------|----------|
| Neural (flat-IR) | 1.0551 | 0.077 | baseline |
| Bigram baseline | 2.3761 | 1.249 | 2.25x worse |
| Unigram baseline | 2.8967 | 1.534 | 2.75x worse |

### Verdict: Is the 1.0551 Result Trivial or Meaningful?

**The result is meaningful, not trivial.**

The neural model achieves 1.0551 perplexity, which is:
- **2.25x better** than the bigram baseline (2.3761)
- **2.75x better** than the unigram baseline (2.8967)

This demonstrates real structural learning beyond simple frequency patterns. The model is learning the sequential structure of IR graphs (E→A→R→O patterns, GRAPH_BEGIN→...→GRAPH_END patterns) in a way that simple n-gram models cannot.

However, DEC-024 correctly notes: this is a **far simpler task** than predicting real mathematical tokens (B/C variants). The SLOT token dominates at 66.6%, making prediction structurally easy.

> **[KIT]** The "2.25x better" framing is technically correct but misleading. The bigram baseline was trained and evaluated on the same eval set — it memorises the eval distribution, making it an optimistic lower bound. A bigram trained on the train set and evaluated on eval would score higher (worse perplexity), making the neural model's advantage even clearer. The verdict "meaningful, not trivial" stands, but the comparison overstates how hard it is to beat the bigram. This caveat is worth noting so the 2.25x figure isn't quoted out of context.

## 5. Assessment of Open Questions from DEC-024

DEC-024 states three open questions. Here is what the existing experimental data shows:

### Question 1: Would more training data (10k+ examples) allow the model to learn semantic content?

**What the data shows:**

The current experiments do not directly test this hypothesis. However:

- The gap between Variant A (1.2751) and B/C (~1.11-1.13) is **stable across corpus sizes**:
  - Phase 5 (2,554 examples): gap ~0.17pp
  - Phase 6 (3,375 examples): gap ~0.15pp  
  - v1.3.0/v1.4.0 (3,491 examples): gap ~0.15pp

- **What this means:** The gap did NOT close when going from 2,554 → 3,375 examples. But we have no data for 10k+ examples.

> **[KIT]** The "Phase 5 (2,554 examples)" figure is incorrect. Phase 5 pre-expansion used the original 4-module corpus (2,213 train / 246 eval = 2,459 total per NORMALISATION_AUDIT.md), not 2,554. The 2,554 figure appears in docs but refers to a specific extraction count that doesn't match any confirmed train/eval split in the results.json files — all Phase 5 matched runs used 3,375 train / 376 eval on the expanded 14-module corpus. The "stable gap" observation is still correct directionally, but citing "Phase 5 (2,554 examples)" as a data point is imprecise. The cleanest statement supported by the data: the gap was ~0.17pp at 3,375 examples (Phase 6, DEC-020/021) and ~0.15pp at 3,491 examples (v1.4.0, DEC-023). The smaller pre-expansion runs are not directly comparable due to different corpus composition.

**Conclusion:** Unverifiable from available data. The hypothesis is plausible but untested.

---

### Question 2: Would probing tasks show semantic content being used?

**What the data shows:**

No probing tasks have been run. The only metric is perplexity.

**Conclusion:** Unverifiable from available data. This would require a separate experimental program.

---

### Question 3: Is the BPE advantage from Qwen pretraining priors or genuine representational advantage?

**What the data shows:**

- DEC-021 (embed_project experiment): Even with warm embeddings projected from Qwen, A still trails B/C by ~0.17pp
- QWEN_PRIOR_ANALYSIS.md reports 25.8% vocab overlap (weak prior)
- Flat-IR achieves 0.077 bits/token vs B's 0.176 — but flat-IR has 66.6% SLOT tokens

**Partial evidence:** The Qwen pretraining prior explanation is weakened by:
1. Low vocab overlap (25.8%)
2. Embed-project experiment still showed the gap

**What this does NOT prove:** Whether the remaining gap is "genuine representational advantage" or some other factor (model architecture, token granularity, etc.)

**Conclusion:** Evidence suggests Qwen prior alone does not explain the gap, but "genuine representational advantage" for BPE is not definitively proven.
